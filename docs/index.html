Connect to your repo

The heavy lifting runs in GitHub Actions in your repo. This page only needs a token that can start those workflows. It's stored in this browser only.

How to create the token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → pick this repo.
  3. Permissions: Actions: Read and write, Contents: Read-only (Metadata is added automatically).
  4. Pick an expiry, generate, and paste it above.
